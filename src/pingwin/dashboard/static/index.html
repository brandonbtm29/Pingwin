    About Pingwin

    Pingwin is a friendly, self-hosted Discord bot. Members tap buttons to choose which pings they get, so a server doesn't need @everyone for every movie night and game day. It runs on your own PC, can keep backup PCs on standby, and updates itself from GitHub.
